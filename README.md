# 気もちの森

どうぶつたちの気もちを見つけて、わけを考える、小学生向けのブラウザゲームです。
1ぴきにつきおはなしが3つ、全9ひき・27話。ひとりで遊べます。

- 全9ひきと1話ずつなかよしになると「しょうじょう」がもらえ、27話ぜんぶで「大の なかよし」になります
- しょうじょうの下に、ゲームの外で試す3つの「ほんものの森へ ちょうせん」があります
- 本体は index.html 1枚で完結します（BGM・アイコンもファイル内に入っています）
- 外部サイトへの通信・広告・アクセス解析・ログインはありません
- 記録・なまえは遊んでいる端末のブラウザ内だけに保存されます
- 画面上部のボタンで、おんがくと効果音を別々に消せます
- 制作：へいなか（https://lit.link/heinaka）／ 転載・再配布は自由です

補助ファイル：ogp.png（SNS用画像）、robots.txt、sitemap.xml、.nojekyll
